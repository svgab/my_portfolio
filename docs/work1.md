# Работа №1: Решение задачи "Two Sum"

## Постановка задачи

Реализовать функцию `two_sum`, которая принимает список целых чисел `lst` и целое число `target`. Необходимо найти два различных индекса `[i, j]` таких, что `lst[i] + lst[j] == target`. Гарантируется, что решение существует, и каждый элемент используется не более одного раза. Функция должна возвращать список из двух индексов в порядке возрастания.

**Пример:**  
Вход: `lst = [2, 7, 11, 15]`, `target = 9`  
Выход: `[0, 1]` (так как `2 + 7 = 9`)

## Исходный код

```python
class Solution:
    '''Returns solutions'''

    def two_sum(self, lst, target):
        '''Returns two_sum's solution'''

        for x in range(len(lst)):
            temp = lst[x + 1:]
            if target - lst[x] in temp:
                return [x, temp.index(target - lst[x]) + x + 1]
```

## Тестирование

Для проверки корректности реализации написаны модульные тесты с использованием `unittest`:

```python
import unittest
import first  # модуль с классом Solution

class TestMySolution(unittest.TestCase):

    def test(self):
        self.assertEqual(first.Solution().two_sum([2, 7, 11, 15], 9), [0, 1])

    def test_same_elems(self):
        self.assertEqual(first.Solution().two_sum([3, 3, 3, 3], 6), [0, 1])

    def test_big_number(self):
        self.assertEqual(first.Solution().two_sum([16, 2, 15, 89], 105), [0, 3])
        self.assertEqual(first.Solution().two_sum([306, 2, 15, 89], 308), [0, 1])

if __name__ == '__main__':
    unittest.main()
```

## Анализ алгоритма

- **Временная сложность:** O(n²) в худшем случае (вложенный поиск `in temp` и `temp.index`).  
  Для каждого элемента `x` выполняется линейный поиск в подмассиве.
- **Пространственная сложность:** O(n) за счёт создания среза `temp` на каждой итерации (хотя сам срез — новая копия списка).

**Возможное улучшение:** можно использовать хэш-таблицу (словарь) для поиска дополнения за O(1), что даст общую сложность O(n) и O(n) памяти.
