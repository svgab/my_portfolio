## 1. Создание классов

Класс – это шаблон для создания объектов, объединяющий данные (атрибуты) и методы. В Python класс определяется с помощью ключевого слова `class`. Внутри класса можно определить метод `__init__` для инициализации атрибутов экземпляра, а также обычные методы, работающие с состоянием объекта.

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y
```

---

## 2. Создание объектов

Объект (экземпляр) создаётся вызовом класса как функции: `obj = ClassName()`. Для удобного создания объектов из разных форматов данных используют **фабричные конструкторы** – методы класса с декоратором `@classmethod`. Они принимают параметр `cls` и возвращают новый экземпляр через `cls(...)`. Это позволяет создавать объекты из строк, кортежей, файлов или получать стандартные экземпляры (например, точку в начале координат).

```python
class Point:
    @classmethod
    def from_string(cls, s):
        x, y = map(float, s.split(','))
        return cls(x, y)
```

## 3. Статические классы

Статический класс – это класс, который не предназначен для создания экземпляров. Все его члены (методы и атрибуты) принадлежат самому классу. В Python статический класс реализуется следующим образом:
- все методы помечаются декоратором `@staticmethod`;
- в `__new__` или `__init__` выбрасывается исключение, чтобы запретить инстанциирование.

```python
class StaticMath:
    def __new__(cls, *args, **kwargs):
        raise TypeError("Статический класс не может быть создан")
    
    @staticmethod
    def add(a, b):
        return a + b
```

---

## 4. Статические методы

Статический метод (`@staticmethod`) – это метод класса, который не принимает ни `self`, ни `cls`. Он работает как обычная функция, но логически принадлежит классу. Применяется для вспомогательных операций (конвертации, валидации, математических вычислений), которые не требуют доступа к состоянию объекта или класса.

```python
class Validator:
    @staticmethod
    def is_positive(n):
        return n > 0
```

## 5. Аксессоры (геттеры, сеттеры, делитеры)

Аксессоры позволяют контролировать доступ к атрибутам. В Python для этого используется декоратор `@property`:
- геттер – получение значения;
- сеттер (`@attr.setter`) – установка значения с проверкой;
- делитер (`@attr.deleter`) – удаление атрибута.

```python
class Person:
    def __init__(self, age):
        self._age = age
    
    @property
    def age(self):
        return self._age
    
    @age.setter
    def age(self, value):
        if value >= 0:
            self._age = value
```

## 6. Инкапсуляция

Инкапсуляция – сокрытие внутреннего состояния объекта и предоставление доступа к нему только через методы. В Python нет строгих модификаторов доступа, но по соглашению:
- `_атрибут` – защищённый (не следует обращаться напрямую);
- `__атрибут` – приватный (имя искажается через *name mangling*).

Вместе с `@property` и методами это позволяет контролировать изменение данных.

```python
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance
    
    def get_balance(self):
        return self.__balance
```

## 7. Наследование

Наследование позволяет создавать новый класс на основе существующего. Дочерний класс автоматически получает атрибуты и методы родителя, может добавлять новые или переопределять унаследованные.

```python
class Animal:
    def speak(self):
        print("Издаёт звук")

class Dog(Animal):
    def speak(self):
        print("Гав!")
```

---

## 8. Полиморфизм

Полиморфизм – способность одного и того же интерфейса работать с объектами разных типов. В Python реализуется через:
- **переопределение методов** в дочерних классах (объект ведёт себя согласно своему типу);
- **утиную типизацию** – если объект имеет нужный метод, он может быть использован, даже если не является наследником определённого класса.

```python
def make_sound(animal):
    animal.speak()

make_sound(Dog())   # Гав!
make_sound(Cat())   # Мяу! (если есть метод speak)
```
