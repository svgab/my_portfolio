    Работа 3: «Генерация бинарного дерева»

    📝 Постановка задачи

    Разработать рекурсивную функцию gen_bin_tree, которая строит бинарное дерево заданной высоты. Каждый узел дерева содержит числовое значение, а левый и правый потомки вычисляются на основе значения родительского узла с помощью переданных функций.

    Параметры функции: - height – высота дерева (количество уровней). По умолчанию 6. - root – значение корневого узла. По умолчанию 5. - left_leaf – функция для вычисления значения левого потомка. По умолчанию: lambda x: x**2 (возведение в квадрат). - right_leaf – функция для вычисления значения правого потомка. По умолчанию: lambda x: x-2 (вычитание 2).

    Требования: - Дерево должно быть представлено в виде вложенных словарей. - Ключ словаря – строковое представление значения узла. - Значение – список из двух элементов: левое поддерево и правое поддерево (каждое – словарь того же формата). - Если поддерево отсутствует (например, из-за условий остановки), его место занимает пустой список. - Высота 0 означает лист: возвращается {str(root): []}.

    💻 Исходный код

    def gen_bin_tree(height=6, root=5,
                 left_leaf=lambda x: x**2,
                 right_leaf=lambda x: x-2):
    """
    Генерирует бинарное дерево заданной высоты.

    Параметры:
        height: int – текущая высота поддерева
        root: число – значение текущего узла
        left_leaf: callable – функция для вычисления левого потомка
        right_leaf: callable – функция для вычисления правого потомка

    Возвращает:
        dict – дерево в формате {str(root): [left_subtree, right_subtree]}
    """
    current = root
    if height == 0:
        return {str(current): []}

    left_value = left_leaf(root)
    right_value = right_leaf(root)

    left_subtree = gen_bin_tree(height - 1, left_value,
                                left_leaf, right_leaf)
    right_subtree = gen_bin_tree(height - 1, right_value,
                                 left_leaf, right_leaf)

    # Если поддерево пустое (из-за отрицательных значений и т.д.),
    # используем пустой список
    left_child = [left_subtree] if left_subtree else []
    right_child = [right_subtree] if right_subtree else []

    return {str(root): left_child + right_child}

    Пример вызова и вывода

    tree = gen_bin_tree(height=2, root=5)
print(tree)

    Результат (сокращённо): 

    {
    '5': [
        {'25': [{'625': []}, {'23': []}]},
        {'3': [{'9': []}, {'1': []}]}
    ]
}

    Расшифровка: - Корень 5 → левый потомок 5² = 25, правый потомок 5-2 = 3. - Узел 25 → левый 25² = 625, правый 25-2 = 23. - Узел 3 → левый 3² = 9, правый 3-2 = 1.

    🧠 Анализ алгоритма

    1. Представление дерева

    Используется рекурсивный словарный формат: - Ключ – значение узла (строка). - Значение – список из двух элементов: левое поддерево и правое поддерево.
    Так как в бинарном дереве строго два потомка, список из двух элементов естественно отражает структуру.

    2. Рекурсивный спуск

    • Базовый случай: height == 0 → возвращается узел без потомков ({str(root): []}).
    • Рекурсивный случай:
    • Вычисляются значения левого и правого потомка через переданные функции.
    • Для каждого потомка рекурсивно строится поддерево с высотой height-1.
    • Собранные поддеревья помещаются в список [left_subtree, right_subtree].
    • Возвращается словарь текущего уровня.

    3. Обработка «пустых» поддеревьев

    В коде есть проверка: 

    left_child = [left_subtree] if left_subtree else []
right_child = [right_subtree] if right_subtree else []
    Это позволяет избежать вставки None или пустых словарей, когда поддерево не может быть построено (например, если функции порождают бесконечную рекурсию или нежелательные значения). Однако для корректной работы высота контролируется параметром height, поэтому left_subtree всегда будет словарём (не None). Данная проверка избыточна, но не вредит.

    4. Временная и пространственная сложность

    • Количество узлов в полном бинарном дереве высоты h (корень на уровне 0) равно 2^(h+1) - 1.
    • Временная сложность – O(2^h), так как каждый узел обрабатывается один раз.
    • Пространственная сложность – O(2^h) для хранения дерева в памяти (результат).

    5. Возможные модификации

    • Использовать мемоизацию (кэширование) для одинаковых поддеревьев (если функции не инъективны).
    • Передать в качестве left_leaf и right_leaf функции с дополнительными параметрами (через lambda или functools.partial).
    • Изменить базовый случай так, чтобы вместо пустого списка возвращался None (тогда формат станет более строгим).

    🧪 Тестирование

    Ниже приведены простые тесты для проверки корректности:

    def test_empty_tree():
    tree = gen_bin_tree(height=0, root=42)
    assert tree == {'42': []}

def test_height_1():
    tree = gen_bin_tree(height=1, root=2, left_leaf=lambda x: x+1, right_leaf=lambda x: x*2)
    expected = {'2': [{'3': []}, {'4': []}]}
    assert tree == expected

def test_default_functions():
    tree = gen_bin_tree(height=1, root=5)
    # left = 5^2=25, right=5-2=3
    assert tree == {'5': [{'25': []}, {'3': []}]}

test_empty_tree()
test_height_1()
test_default_functions()
print("Все тесты пройдены.")

    📊 Выводы по работе

    Что получилось реализовать: - Полностью рабочую рекурсивную функцию построения бинарного дерева с настраиваемыми правилами ветвления. - Гибкость: можно передать любые функции для вычисления левого и правого потомка (например, sin, log, пользовательские выражения). - Удобное представление дерева в виде вложенных словарей – легко сериализовать в JSON или распечатать для отладки.

    Какие были трудности: - Выбор правильного базового случая: если остановиться при height == 0, то листья имеют пустые списки потомков – это логично, но иногда хочется видеть терминальные узлы с None. В текущей реализации лист – это {value: []}. - Избыточная проверка if left_subtree else [] – она не нужна, так как рекурсия всегда возвращает словарь (или пустой список для height=0). Но наличие такой проверки не ломает логику.

    Что нового узнали: - Как рекурсивно строить древовидные структуры данных без использования классов. - Как использовать функции высшего порядка (передача функций в качестве аргументов) для параметризации поведения. - Как представлять бинарное дерево в виде словаря Python – альтернатива классическим узлам с атрибутами left и right.

    Заключение: Задача полностью выполнена. Функция gen_bin_tree универсальна, легко тестируется и может быть использована в учебных проектах, связанных с обходом деревьев, визуализацией или генерацией тестовых данных.
